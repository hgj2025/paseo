## 部署边界

共享界面改动需要更新相应 App / Web 前端；Provider、历史读取、执行与服务端协议改动需要更新对应 host 的 Daemon。一个 host 发布成功不代表所有 host 已升级。

本机安装位置为 `/Applications/Paseo.app`。此前多次仅替换前端资源并刷新窗口；不要据此认为安装包内 Daemon 与当前源码相同。正式发布使用[发布流程](../release.md)。

## host 与连接

使用场景包括 hgj、home、devbox、sg。home 曾通过 Oracle 上的 HTTPS 入口与反向 SSH 隧道接入。具体地址、凭据与当前路由从已授权的设备配置读取，不在仓库复制密码或令牌。

排查连接时沿 App → 入口 → 隧道 → 目标监听 → Daemon 检查。SSH 进程存在并不能证明隧道目标端口有服务。

## 归档规则边界

定期归档由配置规则的 App 协调，关闭或挂起时不执行，重新打开后补检查；不会永久删除 CLI 历史、代码或 worktree。跨客户端归档与开始执行之间仍有竞态，不能描述为服务端原子保护。完整限制见[会话管理](../session-management.md)。
