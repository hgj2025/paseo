# Paseo 项目记忆页面

独立只读插件 `hindsight-memory-viewer`。Paseo 侧栏顶部的「项目记忆」打开原生插件页面，不是外链或嵌入 Hindsight 网页。

支持切换项目记忆库、事实/经历/整合经验筛选、关键词查询、每页 30 条分页、详情、来源证据跳转，以及有 agent_id 元数据时跳转到来源会话。项目库超过 100 个时可切换下一组。搜索使用 Hindsight 列表接口的文本过滤，不调用提炼模型；大量数据的语义检索可另行扩展。

客户端通过 Paseo RPC 请求宿主机，服务器只向该宿主机的 `127.0.0.1:8888` 发出 GET 请求。没有采集生命周期钩子、写入或删除记忆、模型调用、自动启用采集等行为。页面中自动化状态来自最后写入的状态文件，不能视为实时运行证明。

源代码目录为本目录；安装时可直接指向本目录，避免维护源码副本。修改后执行：

```sh
paseo plugin reload hindsight-memory-viewer
```
